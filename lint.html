What it checks

    
    
      
  1. The shape. A recognized type (feat, fix, docs, style, refactor,
      perf, test, build, ci, chore, revert), an optional scope in parentheses, colon, space,
      non-empty subject.
    2. 
      
  2. The voice. Past tense ("added") gets flagged toward imperative ("add"),
      a capitalized sentence start gets flagged, trailing periods get flagged.
    3. 
      
  3. The limits. Subject over 72 characters is an error; the 50-character
      sweet spot is a hint.

Quick questions

    

      Is this commitlint?
      
No — commitlint runs in your repo and CI. This is the quick, pre-commit check for the
      times when there's no hook around: squashing on GitHub's web UI, writing a message on a
      locked-down machine, or reviewing someone else's branch. Output follows the same spec, so
      your commitlint config stays happy.

    

    

      Does my message get uploaded?
      
No. Plain JavaScript in your tab. There is no backend to receive it.
