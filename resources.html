Developer freebies

A hand-picked shelf of specs, references and free tools — the same ones we use while building this site. Every entry earns its place by being the thing we actually open. Suggest more via the version history page's changelog-style updates; the shelf grows every week.

Specs & standards

The documents that decide what your commits, releases and APIs mean.

conventionalcommits.org The spec this whole site implements. One page, worth knowing by heart.
keepachangelog.com What a changelog is for, and what belongs in it. Our changelog drafts follow this spirit.
semver.org Why the version number says 1.4.0 and not 1.4. Short, final, binding.
12factor.net The twelve factors behind deployable apps. Older than most frameworks, still correct.

Rescue & reference

For the moments when git, shell or CSS stops making sense.

ohshitgit.com Git disasters, indexed by what you just did, with the exact commands to survive. A classic for a reason.
explainshell.com Paste any shell command, see what every flag does. The only way to read find . -exec safely.
git-scm.com/doc The official git book and docs. When the rescue sites run out, this is the source.
crontab.guru The cron expression explainer. Five fields in, plain English out. Proof that one page done well can serve for decades.
developer.mozilla.org (MDN) The web platform's real documentation. If you're copy-pasting from anywhere else, start here instead.
caniuse.com Which browsers support which features, with the numbers that end arguments.

Free tiers & handy tools

Things that cost nothing and stay useful.

free-for.dev Thousands of services with real free tiers, grouped by category and kept current by a large community. The first stop before paying for anything infra.
gitignore.io .gitignore templates for any stack combination. Saves the first commit of every project from shipping node_modules.
roadmap.sh Community-built learning roadmaps for nearly every developer role. Good for finding the next skill, not just the next framework.
