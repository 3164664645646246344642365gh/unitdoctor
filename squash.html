How the title gets picked

    
    
      
  1. Count the types. The branch's subjects are tallied — if most commits are
      feat, the title leads with feat; if there's a single
      fix among chores, the fix wins anyway because it matters more.
    2. 
      
  2. Scope follows the majority. The most common scope across the branch
      rides along — feat(auth) if most touches were auth.
    3. 
      
  3. Breaking changes shout. One breaking commit turns the title into
      feat!: and the body says why.
    4. 
      
  4. The body is the receipt. Every subject from the branch is listed, so the
      squash merge still tells the whole story.

Quick questions

    

      Why not just let Copilot write the squash title?
      
On GitHub's web UI there's no assistant in the squash box, and on locked-down machines
      there's no extension to install. This page needs nothing but a browser tab — and it takes
      the branch log you already copied.

    

    

      Does my branch history get uploaded?
      
No. Plain JavaScript in your tab. There is no backend to receive it.
