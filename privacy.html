Privacy

Short version: we can't see your code, because we have nowhere to receive it.

How the tool works, privacy-wise

unitdoctor.online is a set of static files. When you paste a git diff or a description, the analysis and message generation run entirely as JavaScript inside your browser tab. There is no backend endpoint that accepts tool input. Your diff is not transmitted, logged, or stored by us — it never leaves your machine.

What is stored, and where

  • Your style profile (if you use "Teach it your style") — saved in your browser's localStorage on your device. It contains aggregated counts (type frequencies, subject length, casing habits), never your actual code.
  • Recent generations (last 20 commit messages) — also localStorage, also your device. You can erase both at any time with the "Forget my style" and "clear history" controls, or by clearing site data.

Cookies and tracking

We set no cookies. We do not run advertising or cross-site trackers. If we later add privacy-friendly aggregate analytics (such as page-view counts without any identifier), it will never include tool input — and we'll note it on this page first.

Third parties

The site is served over a CDN (Cloudflare), which processes standard request metadata (IP address, user agent) as any web server does, under Cloudflare's own privacy policy. Nothing about the content you paste is involved, because that content is never sent.
